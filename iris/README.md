# Iris Dataset

The Iris dataset is a classic machine learning benchmark originally collected by R. A. Fisher and now widely used to demonstrate classification methods. It contains 150 flower samples from three iris species: Iris Setosa, Iris Versicolour, and Iris Virginica. Each class has 50 instances, making the dataset balanced and easy to interpret.

The purpose of the dataset is to predict the iris species from four numeric measurements: sepal length, sepal width, petal length, and petal width. All attributes are continuous, measured in centimeters, and there are no missing values. Because the data is small and tabular, it is often used as a first example for exploratory data analysis, supervised learning, and model comparison.

One notable observation is that petal length and petal width are highly informative for separating the classes. Iris Setosa is linearly separable from the other two species, while Versicolour and Virginica overlap more and are harder to distinguish. This makes the dataset useful for showing both simple and imperfect classification behavior in a compact example.

Overall, the Iris dataset is a clean, well-documented benchmark for understanding feature relationships, class separation, and basic classification workflows.
